Scripting du cheat en Lua

Le cheat embarque un moteur Lua 5.4 complet. Les scripts sont chargés depuis le tab Lua du menu (bouton Run), ou placés dans Documents/gamesense-cs2/scripts/.

L'API expose 80+ fonctions couvrant le rendu, les entités, la mémoire du jeu, la bombe, les angles de vue, la configuration et des widgets de menu natifs.

Démarrage rapide basics

Un script Lua s'exécute une fois au chargement (le code top-level), puis s'enregistre sur des événements via des callbacks. L'état persiste entre les frames dans les variables locales et globales du script.

-- script minimal : affiche un texte en haut à gauche
client.set_event_callback("paint", function()
    render.text("hello", 10, 10, 255, 255, 255, 255, TEXT_LEFT)
end)

Structure d'un script typique avec UI et rendu :

-- 1. déclarer l'UI (appelée quand le panneau Script options se dessine)
client.set_event_callback("menu", function()
    local enabled = ui.checkbox("my_enabled", "Enabled", true)
    _G.CFG = { enabled = enabled }
end)

-- 2. dessiner chaque frame
client.set_event_callback("paint", function()
    if not _G.CFG or not _G.CFG.enabled then return end
    render.text("actif !", 10, 10, 120, 255, 120, 255, TEXT_LEFT)
end)

Écriture de fichiers (persistance des réglages) :

fs.write("mes_reglages.txt", "speed=1.5\nmode=2")
local data = fs.read("mes_reglages.txt")  -- nil si absent

Événements callbacks

Les scripts s'exécutent via des callbacks enregistrés avec client.set_event_callback(event, fn). Un seul callback par événement (le dernier enregistrement remplace).

ÉvénementQuandUsage typique
"paint"Chaque frame de renduDessin overlay (render.*)
"run"Chaque tick de logiqueLogique, input, mouvements
"menu"Dessin du panneau Script optionsWidgets ui.* (tab Lua du menu)
Important : les widgets ui.* (checkbox, sliders, combo...) ne doivent être appelés que dans le callback "menu". Les fonctions render.* que dans "paint". game.set_view_angles ne fait rien si le menu est ouvert (protection du freeze d'angles).

Exemples complets recipes

Bomb timer HUD

client.set_event_callback("paint", function()
    if bomb.state() ~= BOMB_TICKING then return end

    local t = bomb.timer()
    local w, h = client.screen_size()
    local r = t < 10 and 255 or 200
    local g = t < 10 and 50 or 200

    render.text(string.format("C4 [%s] %.1f", bomb.site(), t),
        w/2, h - 120, r, g, 60, 255, TEXT_CENTER)

    if bomb.being_defused() then
        render.text(string.format("DEFUSING %.1fs", bomb.defuse_progress()),
            w/2, h - 100, 80, 180, 255, 255, TEXT_CENTER)
    end
end)

Enemy tracker avec world_to_screen

client.set_event_callback("paint", function()
    for _, p in ipairs(entity.get_players(true)) do
        if p.x then
            local sx, sy = render.world_to_screen(p.x, p.y, p.z)
            if sx then
                render.text(p.name .. " [" .. p.health .. "hp]",
                    sx, sy, 255, 200, 80, 240, TEXT_CENTER)
            end
        end
    end
end)

Menu script complet avec sauvegarde

client.set_event_callback("menu", function()
    ui.label("== Mon script ==", true)
    local on    = ui.checkbox("on", "Enabled", true)
    local speed = ui.slider_float("spd", "Speed", 0.1, 5.0, 1.0)
    local mode  = ui.combo("mode", "Mode", {"Lent", "Normal", "Rapide"}, 1)
    local col   = ui.color_picker("col", "Couleur", {r=120,g=180,b=255,a=255})
    local key   = ui.keybind("key", "Hotkey", 0)
    if ui.button("save", "Sauvegarder") then
        fs.write("mon_script.cfg",
            string.format("on=%s speed=%.2f mode=%d", tostring(on), speed, mode))
        client.notify("Sauvegardé !")
    end
    _G.MY = { on = on, speed = speed, mode = mode, col = col, key = key }
end)

client.set_event_callback("paint", function()
    local M = _G.MY
    if not M or not M.on then return end
    local t = client.realtime() * M.speed
    local w, h = client.screen_size()
    render.filled_rect(0, 0, w * (t % 1), 4,
        M.col.r, M.col.g, M.col.b, M.col.a)
end)

Reading game memory via offsets

client.set_event_callback("paint", function()
    local client = memory.get_module("client.dll")
    local pawn  = memory.read_int(client + memory.get_offset("client", "dwLocalPlayerPawn"), 8)
    if pawn == 0 then return end

    local hp = memory.read_int(pawn + memory.get_offset("entity", "m_iHealth"))
    local team = memory.read_int(pawn + memory.get_offset("entity", "m_iTeamNum"), 1)
    render.text(string.format("HP:%d TEAM:%d", hp, team),
        10, 200, 255, 255, 255, 255, TEXT_LEFT)
end)
